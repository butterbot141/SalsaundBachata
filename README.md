# Salsa & Bachata – Tanzschritte

Offline-Web-App, um Videos aus dem Tanzkurs zu sortieren und übersichtlich darzustellen:
Salsa, Bachata und Rueda – mit Ablauf, Counts, Notizen, Würfel und Übungstakt.

## Nutzen
- Öffnen: https://butterbot141.github.io/SalsaundBachata/ → im Browser „App installieren“
- Videos bleiben auf deinem Gerät (werden in der App importiert, nicht hochgeladen)
- Schritte kommen nach und nach aus dem Kurs; neue Versionen ersetzen nur die index.html

## Eigene Version
Repository forken, GitHub Pages aktivieren und die Schritte im `<script id="data">`-Block
der index.html anpassen – oder in der App eigene Schritte anlegen und exportieren.
